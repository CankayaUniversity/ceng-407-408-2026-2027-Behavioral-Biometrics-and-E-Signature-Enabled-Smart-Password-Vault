# Mobile Application

Planned Android and iOS application for the project's secure password vault.

## Planned MVP Features

- Encrypted vault access and credential management.
- Encrypted synchronization between desktop and mobile.
- Credential autofill through platform-supported integrations.
- Approval or rejection of desktop sign-in requests.
- Account and vault recovery workflows.

## Status

Scaffolding only. No mobile functionality is implemented yet.

The mobile framework, device pairing protocol, synchronization design,
and recovery architecture are pending team review.
